# LAKSHYA.EXE

An experimental portfolio experience for Lakshya Bhandari.

## Runtime

Vite 8 requires Node.js 20.19+ or 22.12+. The system Node in this WSL environment is Node 18, so either install Node 22 in WSL or run the commands through npm's temporary Node 22 package:

```sh
npm exec --yes --package=node@22 -- npm install
npm exec --yes --package=node@22 -- npm run dev
```

For a compatible Node installation, `npm install` and `npm run dev` are sufficient.

## Phase 1

This phase contains the cinematic identity intro, a face-derived pixel portrait, and a scroll transition to a clearly marked Phase 2 placeholder. Portfolio sections are intentionally out of scope. Centralized source content stays in `content/`, and supplied portraits stay in `public/images/`.
